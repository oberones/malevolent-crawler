## Delivered boundaries

- `assets/js/app/save-validation.mjs`: pure detached validation for `legacy`, complete `state`, `snapshot`, and `character` source kinds. Validates player/stat/experience/item/run/enemy/preferences relationships, exact engine-facing legacy tokens, both portrait variants, finite values, six equipped slots and safe catalog references. Preserves sequence, duplicate holdings, player-authored text, fractional values and legitimate null/derived fields. Adds fixture-backed optional defaults without RNG or storage. Character previews do not require an enemy. Active terminal/incomplete states remain recoverable errors; resting flags and run resets are not silently changed.
- Resource safeguards check UTF-8 input/serialized size at 16 MiB, nesting at 64 and individual strings at 64 KiB. Preflight runs before parsing or cloning, rejects accessors/prototype keys/cycles/non-JSON values, and measures JSON size without an arbitrary inventory/history count cap. Each encoded item is decoded and validated independently. Unknown historical strings remain raw data; history conversion is assigned to US5.
- `message-records.mjs` and `safe-render.mjs`: exact typed parameter schemas, trusted template registration and a small inert DOM vocabulary. Text uses text nodes; image paths/rarity classes come only from catalogs. Arbitrary HTML, CSS, attributes and URLs are refused. `history.unavailable` has a reserved neutral notice and optional Recover history button using an opaque recovery reference. US1 owns narrative templates; symbol geometry and image loading remain later services.
- `snapshot-store.mjs`: `createSnapshotStore({storage, now, eventTarget})` returns `readLocalState`, `commitSnapshot`, and `dispose`. A read is required before writing. Reads select one complete canonical revision or a validated legacy tuple, preserve raw recovery sources, and never downgrade malformed canonical data. Fresh preferences can load independently; malformed preferences return documented defaults plus issues and raw recovery bytes. Backups receive exact canonical bytes before replacement. Every failed stage returns unsaved/conflict without rollback or legacy writes. Revision and raw-byte rechecks plus optional storage-event observation suspend detected foreign writes; this is not an atomic cross-tab lock.
- `lifecycle.mjs`: explicit clock, guarded generation callbacks, owned timeouts/intervals/listeners/audio and consumer cleanup. Invalidate releases the current generation; dispose permanently closes the owner. Every disposer is attempted and failures return sanitized issues. Timer completion and individual cancellation release retained ownership.
- `transitions.mjs`: nested synchronous save requests coalesce into one validated outer snapshot after rewards/HP mutations finish. Exceptions, including caught nested failures, suppress persistence; requests outside transitions are refused. Async callbacks/returned promises are unsupported and reported; rejected returned promises do not leak unhandled rejections. Engine state ownership and rollback policy remain with the caller. The service never installs import/migration candidates into live state.
- `dialogs.mjs`: one existing modal per service, native controls, explicit document/lifecycle/trigger dependencies, initial focus, Tab wrapping, Escape cancellation, inert background branches, exact attribute restoration and focus return. Pointer callers must pass `invoker` because WebKit does not necessarily focus a clicked button. Disposal/generation invalidation restores the page without confirming or cancelling a destructive action.

These services are independently tested but **not yet connected to gameplay**. Phase 2G owns the bridge and existing save-site integration. Character encoding, confirmed import/reset, continuation timing, full recovery UI and historical template migration remain US5 work. Rendering raw history or bypassing these boundaries in untouched classic code is not repaired by merely adding the modules.
